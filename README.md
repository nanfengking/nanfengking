## `01 / ABOUT`

I'm an **engineering undergraduate at Jilin University**, interested in **embedded systems, robotics and artificial intelligence**.

I build things at the intersection of software and physical systems — from microcontroller-level control to real-time computer vision and edge intelligence.

- **Engineering:** C / C++, embedded development, intelligent hardware
- **Intelligence:** Computer vision, machine learning, edge AI
- **Exploration:** Robotics, systems programming, open-source projects
